# Python Basics

This repository contains small Python exercises and projects created while learning programming.

## Projects

### Calculator

A simple calculator that can add and subtract two numbers.

## Topics Practised

- Functions
- User input
- Conditional statements
- Basic arithmetic
- Floating-point numbers

## How to Run

1. Install Python 3.
2. Open a terminal in this repository.
3. Run:

```bash
python calculator.py
```
